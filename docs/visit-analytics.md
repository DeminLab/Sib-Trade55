# Журнал посещений

Раздел `/admin/visitors` показывает посетителей витрины, число визитов и просмотров, тип устройства, браузер, операционную систему, источник перехода, открытые страницы и первое/последнее время активности (время отображается по Омску).

Посетителю назначается случайный first-party ID браузера: он хранится в cookie `sib_trade_visitor` сроком на год и дублируется в `localStorage` для сохранения идентификатора при клиентских переходах. ID не содержит IP или иных личных данных. Страница считается новым визитом только после перерыва свыше 30 минут; переходы между страницами увеличивают просмотры, но не число визитов. Визиты сохраняются в таблице `site_visits` текущей SQLite базе и переживают перезапуск приложения. Для авторизованного покупателя к визитам добавляются ID и email из подписанной серверной сессии; администраторские сессии не записываются. Анонимного человека нельзя достоверно определить по имени: ему виден только псевдонимный ID браузера.

Источник берётся из `document.referrer`: записываются только домен и путь без query-параметров. Если браузер его не передал, источник будет показан как прямой переход. IP-адрес, точная геолокация и полный User-Agent не сохраняются. Устройство, браузер и ОС определяются на сервере по User-Agent.

Витрина отправляет просмотр для первоначальной загрузки и клиентских переходов. Просмотр не записывается для административных страниц, API, файлов и изображений. Журнал доступен только после серверной проверки сессии администратора; API ответов не кеширует. В текущей реализации история не удаляется автоматически.

Перед публикацией проверьте, что политика конфиденциальности сайта описывает эту обработку данных и срок их хранения.
