# Постоянный администратор

Администраторы сохраняются в таблице `admin_accounts` базы `data/catalog.sqlite` (или базы из `SQLITE_DATABASE_PATH`). При запуске Node-сервера аккаунт из `ADMIN_EMAIL`, `ADMIN_PASSWORD` и `ADMIN_NAME` создаётся только при отсутствии такого email. Идентификатор аккаунта постоянный. Повторные запуски и изменения начального пароля в окружении не сбрасывают существующий пароль.

Локальное создание:

```powershell
npm run admin:create
```

На сервере после обновления кода и пересоздания контейнера аккаунт создаётся автоматически из серверных `ADMIN_*`. Локальная база не переносится через Git; если серверные данные входа отличаются, сервер получит аккаунт с этими данными. Для сохранения аккаунта между обновлениями нужен существующий том `sib_trade_data`.

После создания можно удалить `ADMIN_EMAIL` и `ADMIN_PASSWORD` из окружения. `AUTH_SESSION_SECRET` сохраняйте: он нужен для подписанных сессий. Вход — `/auth/login`, панель — `/admin`. Демо-аккаунты доступны только в разработке.

Пароль хранится как scrypt-хеш с отдельной случайной солью; в ответы API хеш не попадает. Параметры `N=32768, r=8, p=3` соответствуют одному из [рекомендованных вариантов OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html). Используется встроенная [реализация Node.js](https://nodejs.org/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback). Пароли, хеши, `.env` и SQLite не коммитятся.
